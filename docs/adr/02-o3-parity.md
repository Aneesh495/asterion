# Preserve reflection parity

Status: implemented.

SO(3) covariance alone does not establish reflection behavior. Hidden blocks use the polar parity (-1)^l and complete-irrep scalar gates. e3nn supplies intertwiners and harmonics; block composition, readout and training remain original. This avoids componentwise vector nonlinearities but introduces tensor-product cost.

The consequences are exercised through the standard model, training, simulation or verifier path. Full scientific acceptance remains a separate execution obligation.
