# Contributing

Keep scientific comparisons separate from implementation correctness. A failing detector case
is retained evidence, not a reason to replace model forces with an oracle. Use explicit units,
tensor axes, irrep parity and electronic-structure levels at interfaces. Validate label access
against a frozen split and reveal ledger. New chemistry needs a new task contract and experiment.

Run Ruff, mypy, pytest, package builds and documentation checks. Add independent mathematical
references or meaningful negative paths when changing numerical behavior. A production method
cannot generate its own expected answer. Source changes invalidate final evidence.

Use concise technical descriptions without promotional claims. Make real coherent commits.
Do not commit author datasets, private credentials, run directories or large tensor checkpoints.
Never report a diagnostic profile as complete full acceptance.
